# 20 proposed worlds and their casts

Each world is a skin: the same ledger, rooms, vault, dock and mast, dressed differently. "Made" means the cast is
new, drawn with this kit. "Code Lab" means the cast is picked from the Code Lab handoff (classes, species, foes
and bosses) and would be redrawn with this kit so it matches the Proxyfolk folk.

A boss never appears for show. Each one stands for a real ledger event, and only turns up when that event happens.

## New characters for the current worlds

These fill gaps in the six worlds that already exist.

- **Space:** a cargo-loader robot for the dock and a zero-g Runner who floats between rooms.
- **Castle:** Mordra as the vault keeper; Vex as the Outreach drafter (a hooded scribe); Grubbs as runners.
- **Farm:** Mumblecrow as the scarecrow in a field with no leads; Mott as the farm cat; Warg as the sheepdog.
- **Cyber:** a courier on a hoverboard at the dock; a DJ robot for the Content studio.
- **Alien:** a blob receptionist; grey Tycoons with floating crowns.
- **Ocean:** an octopus accountant at the vault (eight arms, eight ledgers); crab couriers at the sub dock.
